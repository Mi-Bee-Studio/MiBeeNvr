MP4Muxer Integration into H264Recorder - Evidence
===================================================

Date: 2026-04-30

## Changes Made

### 1. internal/recorder/h264.go (primary target)
- Added `muxer *muxer.MP4Muxer` field to H264Recorder struct
- Added `trackID int` field to H264Recorder struct
- Added `curTempPath string` field to track and clean up orphaned temp files
- Added `"os"` import for temp file cleanup
- `writeFrames()` method now:
  - Creates MP4Muxer when first video frame arrives (with SPS/PPS available)
  - Calls `muxer.AddH264Track(sps, pps)` to initialize H264 track
  - Calls `muxer.WriteSample(trackID, nalu, pts, duration)` for each video frame
  - PTS calculated as `time.Since(segStart)`, duration as inter-frame delta (min 33ms)
  - Cleans up temp file on muxer init failure
- `closeCurrentSegment()` method now:
  - Calls `muxer.Close()` to finalize MP4 (writes ftyp + moov + mdat)
  - Removes orphaned .tmp file created by CreateSegment
  - Resets muxer fields
