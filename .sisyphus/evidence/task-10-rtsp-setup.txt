### Step 6: Pipeline Architecture
```
rpicam-vid (H.264) -> pipe -> ffmpeg (MPEG-TS mux) -> UDP 127.0.0.1:8555 -> mediamtx
```
Full command chain:
```bash
# mediamtx
cd /tmp && ./mediamtx mediamtx.yml &

# rpicam-vid piped through ffmpeg for MPEG-TS wrapping
rpicam-vid -n --codec h264 --width 1280 --height 720 --framerate 15 -t 0 -o - | \
ffmpeg -fflags +genpts -i pipe:0 -c:v copy -f mpegts -flush_packets 0 "udp://127.0.0.1:8555?pkt_size=188" &
```

### Issues Encountered & Resolutions

1. **libcamera-hello not found**: Binary renamed to rpicam-hello in Debian Bookworm+. Use `rpicam-*` commands.

2. **mediamtx exec:// not supported**: v1.11.3 doesn't support exec:// source. Use UDP pipe approach.

3. **h264_ts codec not available**: rpicam-vid only supports h264, libav, mjpeg, yuv420. Use ffmpeg for TS muxing.

4. **UDP TS packet alignment error**: "received packet with size 1472 not multiple of 188" - Fixed by adding `?pkt_size=188` to ffmpeg UDP output URL.

5. **SSH background process issues**: Background processes started via SSH don't survive. Used a shell script on the RPi to start all processes.
