## Systemd Service Deployment - Task Streaming Pipeline (May 1, 2026)

### Files Created

#### 1. mediamtx.service
Location: /home/mickey/Projects/iot/rpi3b-storeage/deploy/mediamtx.service

```ini
[Unit]
Description=MediaMTX Streaming Server
After=network.target

[Service]
Type=simple
User=mickey
ExecStart=/usr/local/bin/mediamtx /etc/mediamtx/mediamtx.yml
WorkingDirectory=/etc/mediamtx
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

#### 2. rpicam-stream.service  
Location: /home/mickey/Projects/iot/rpi3b-storeage/deploy/rpicam-stream.service

```ini
[Unit]
Description=Raspberry Pi Camera Streaming Pipeline
Wants=mediamtx.service
After=mediamtx.service

[Service]
Type=simple
User=mickey
ExecStart=/bin/bash -c 'rpicam-vid -n --codec h264 --width 1280 --height 720 --framerate 15 -t 0 -o - | ffmpeg -fflags +genpts -i pipe:0 -c:v copy -f mpegts -flush_packets 0 "udp://127.0.0.1:8555?pkt_size=188"'
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```
