# 双模式延时摄影配置教程

双模式延时摄影是 MiBee NVR v2 引入的核心功能，允许任意 RTSP 或 ONVIF 摄像头在常规录制的同时，通过关键帧提取生成延时摄影视频。本教程将指导你通过 Web 界面完成配置。

本教程完全使用 Web UI 操作，无需编辑 YAML 配置文件。

---

## 前提条件

在开始之前，请确保：

- **MiBee NVR v2+**：版本 2.0 或更高，支持双模式延时摄影
- **RTSP / ONVIF 摄像头**：已添加到 NVR 并处于录制状态
- **NVR Web 界面**：可通过浏览器访问（默认端口 9090）
- **管理员权限**：拥有 Web UI 的登录凭据

本教程以 ONVIF 摄像头为例。RTSP 摄像头操作步骤相同。

---

## 操作步骤

### 步骤 1：登录 Web 界面

打开浏览器，访问 NVR Web 界面地址（例如 `http://your-nvr-ip:9090`）。

输入用户名和密码，点击 **登录**。

![登录页面](images/timelapse-dual-mode/step-1-login-page.png)

> **注意**：如果首次登录，请使用安装时设置的管理员密码。本教程使用 `[your-password]` 表示你的实际密码。

---

### 步骤 2：进入摄像头管理

登录后，点击顶部导航栏的 **摄像头** 进入摄像头列表页面。

![摄像头列表](images/timelapse-dual-mode/step-2-cameras-list.png)

页面以卡片网格形式展示所有已添加的摄像头，每张卡片显示摄像头名称、协议、编码格式、状态等信息。

---

### 步骤 3：打开摄像头编辑表单

找到需要配置延时摄影的摄像头（例如本教程中的 **ONVIF Cam**），点击卡片右下角的 **更多操作**（⋮ 图标）按钮，在下拉菜单中选择 **编辑**。

![打开下拉菜单](images/timelapse-dual-mode/step-3-dropdown-menu-open.png)

点击编辑后，页面顶部将显示摄像头编辑表单。

![摄像头编辑表单](images/timelapse-dual-mode/step-4-camera-edit-form.png)

编辑表单包含摄像头名称、协议、URL、认证信息等基本设置。延时摄影配置在表单下方的独立区域。

> **提示**：如果你需要修改摄像头的基本设置（如名称、URL、用户名密码），可以在此表单中修改。配置延时摄影不需要修改这些字段。

---

### 步骤 4：找到延时摄影配置区域

向下滚动到编辑表单下方，找到 **Timelapse**（延时摄影）配置区域。该区域是一个可折叠的 `<details>` 面板。

处于折叠状态时，仅显示标题行，右侧标注当前状态（"已启用"或"已禁用"）。

![延时摄影区域（折叠）](images/timelapse-dual-mode/step-5-timelapse-collapsed.png)

点击标题行 **Timelapse** 展开配置面板。

![延时摄影区域（展开）](images/timelapse-dual-mode/step-6-timelapse-expanded.png)

展开后可以看到所有配置项：启用开关、抽帧间隔、帧源选择、合并设置等。

---

### 步骤 5：配置双模式延时摄影

按照以下顺序填写配置：

#### 5.1 启用延时摄影

勾选 **Enabled**（启用）复选框。启用后，下方配置选项将变为可编辑状态。

#### 5.2 设置抽帧间隔

在 **Interval**（间隔）输入框中填写 `30s`。这个值表示每 30 秒从视频流中提取一帧作为延时摄影素材。

支持的格式：
- `10s` — 每 10 秒一帧（高密度）
- `30s` — 每 30 秒一帧（推荐）
- `60s` — 每 60 秒一帧（低密度）
- `5m` — 每 5 分钟一帧（极低密度，适合长时间监控）

#### 5.3 选择帧源

在 **Frame Source**（帧源）下拉菜单中选择 **RTSP Keyframe**（RTSP 关键帧）。

帧源选项说明：

| 选项 | 说明 | 适用场景 |
|------|------|----------|
| Auto | 自动选择最佳帧源 | 通用场景 |
| Snapshot | 使用摄像头快照 URL | 不支持 RTSP 的摄像头 |
| **RTSP Keyframe** | 从 RTSP 流中提取关键帧（推荐） | 所有 RTSP/ONVIF 摄像头 |
| MJPEG | 使用 MJPEG 流 | MJPEG 摄像头 |

**RTSP Keyframe** 是双模式延时摄影的核心——它直接从现有 RTSP 流中提取 IDR 关键帧，无需额外的网络带宽或硬件资源。

#### 5.4 配置合并设置

在 **Merge Settings**（合并设置）区域：

- **Merge Mode**（合并模式）：选择 `auto`（自动），系统会自动选择最佳的合并方式（MP4 或 JPEG）
- **Daily Merge**（每日合并）：保持勾选，系统每天自动将当天的关键帧合并为延时摄影视频
- **Merge Duration**（合并间隔）：选择合并周期，例如 `natural-day`（自然日）或 `24h`（24 小时）
- **Merge Output FPS**（合并输出帧率）：输出视频的帧率，建议 `30` FPS

完整的配置示例如下：

![延时摄影配置完成](images/timelapse-dual-mode/step-7-timelapse-configured.png)

---

### 步骤 6：等待自动保存

MiBee NVR 的延时摄影配置采用**防抖自动保存**机制。修改任何配置项后，系统会在 **800 毫秒** 内自动保存，无需手动点击保存按钮。

等待约 3 秒，确保配置已保存。保存期间，Timelapse 标题行右侧会显示旋转加载动画。

![自动保存完成](images/timelapse-dual-mode/step-8-timelapse-saved.png)

> **验证保存成功**：观察页面是否有错误提示（Toast 通知）。如果保存成功，不会出现任何错误弹窗。配置会自动持久化到 NVR 配置文件。

---

### 步骤 7：查看 ONVIF 事件（可选）

对于 ONVIF 摄像头，编辑表单下方还包含 **ONVIF 设备设置** 区域，其中 **Events**（事件）面板可以查看摄像头的 ONVIF 事件（如移动侦测、视频丢失等）。

点击 **Events** 标题行展开面板：

![ONVIF 事件面板](images/timelapse-dual-mode/step-9-onvif-events.png)

> ONVIF 事件面板加载正常代表 ONVIF 接口通信正常，无认证错误。

## 配置项说明

### 基本设置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| Enabled | 复选框 | 关闭 | 启用/禁用延时摄影功能 |
| Interval | 文本 | `60s` | 帧提取间隔，支持 `s`（秒）和 `m`（分钟） |
| Frame Source | 下拉选择 | `auto` | 帧源类型：auto / snapshot / rtsp_keyframe / mjpeg |
| Snapshot URL | 文本 | 空 | 当帧源为 snapshot 时需填写快照 URL |
| Delete Original | 复选框 | 关闭 | 合并后是否删除原始帧文件 |

### 合并设置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| Merge Mode | 下拉选择 | `auto` | 合并方式：auto（自动）/ mp4 / jpeg |
| Daily Merge | 复选框 | 开启 | 是否每天自动合并 |
| Merge Duration | 下拉选择 | `natural-day` | 合间隔：8h / 12h / 24h / natural-day / 7d / 30d |
| Merge Output FPS | 数值 | `30` | 输出视频帧率，范围 1-60 |

### 合并间隔选项

| 间隔 | 对齐方式 | 用途 |
|------|----------|------|
| `8h` | 00:00、08:00、16:00 UTC | 商务时段、班次变化 |
| `12h` | 00:00、12:00 UTC | 日/夜周期、上午/下午片段 |
| `24h` | 每天 00:00 UTC | 日概览、安全审查 |
| `natural-day` | 本地时间 | 用户友好的日总结（推荐） |
| `7d` | 周一 00:00 UTC | 周度审查、模式分析 |
| `30d` | 每月 1 日 00:00 UTC | 月度报告、长期分析 |

---

## 预期效果

完成配置后：

1. **即时生效**：配置保存后，NVR 后台会自动启动 KeyframeExtractor（关键帧提取器）
2. **零额外带宽**：关键帧提取直接从现有 RTSP 流中获取数据，无需额外的网络连接
3. **低资源占用**：无需视频解码，仅提取 IDR 帧，CPU 和内存开销极小
4. **自动合并**：根据设置的合并间隔，系统会在每个周期结束时自动将帧合并为延时摄影视频

## 查看延时摄影

配置完成后，延时摄影录制会自动生成。你可以通过以下方式查看：

### 1. 录像页面

点击顶部导航栏的 **录像**，进入录像列表页面。

### 2. 格式过滤

在页面顶部的格式过滤器中点击 **⏱ Timelapse**（或所有格式 **All**），即可查看所有延时摄影录制。

### 3. 视图模式

支持多种视图模式：

- **表格视图**：`#/recordings?view=table` — 列表显示录制详情
- **图库视图**：`#/recordings?view=gallery` — 缩略图画格布局
- **日历视图**：`#/recordings?view=calendar` — 基于日历的日期导航

### 4. 下载与播放

点击延时摄影录制卡片上的操作按钮，可以 **播放** 或 **下载** 延时摄影视频。

## 常见问题

**Q：延时摄影没有生成？**
A：检查摄像头是否处于录制状态（状态显示"录制中"）。延时摄影依赖于实时视频流。

**Q：帧源选择 RTSP Keyframe 但不见效？**
A：确保摄像头编码为 H.264 或 H.265，且 RTSP 流中包含 IDR 关键帧。

**Q：合并间隔如何选择？**
A：根据监控需求选择。日常监控推荐 `natural-day`，长期分析推荐 `7d` 或 `30d`。

**Q：配置没有自动保存？**
A：检查浏览器控制台是否有错误信息。如果自动保存失败，可以尝试刷新页面后重新配置。
