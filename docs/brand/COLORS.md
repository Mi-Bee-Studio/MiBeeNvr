# MiBee NVR — Brand Colors

Authoritative palette for the logo and UI accents. Source of truth for any
brand-aligned artwork, deployment icons, or marketing material.

| Role | HEX | RGB | Usage |
|------|-----|-----|-------|
| Primary — Stripe indigo | `#635bff` | `rgb(99, 91, 255)` | Brand primary / gradient start |
| Deep purple | `#3a1c9e` | `rgb(58, 28, 158)` | Gradient end / stroke / shadow |
| Bee warm yellow | `#ffd166` | `rgb(255, 209, 102)` | Bee tail accent |
| Recording red | `#ff4d5e` | `rgb(255, 77, 94)` | REC indicator dot |
| Night blue | `#1b1147` | `rgb(27, 17, 71)` | Lens core / dark fill |

## Asset inventory (`docs/brand/`)

- **`logo-package.svg`** — rounded-square "app package" icon (gradient background).
  Use for NAS app-store icons (Synology / QNAP / unRAID), and PWA maskable.
- **`logo-icon.svg`** — transparent-background mark. Use for favicons, document
  headers, and the README banner.
- **`icon-{16,32,48,64,128,256,512}.png`** — pre-rendered transparent icons.
- **`mibee-nvr-{72,128,192,256,512}.png`** — pre-rendered rounded-square icons.
